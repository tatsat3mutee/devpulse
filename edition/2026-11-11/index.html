Durable execution lets long-running agents resume after failures

The runtime records results from steps that interact with external systems, then skips completed steps and rebuilds state after a failure. This pattern helps agents make progress across crashes, network faults and work that spans days or weeks.

  • WhatDurable execution is a programming model that helps long-running agents recover from process crashes, network failures, and unexpected real-world behavior.
  • HowThe runtime records results of external steps; after a failure, the program reruns, skips completed steps, and rebuilds state from the record.
  • Why it mattersFor agents working over days or weeks, recorded progress helps preserve completed work while waiting on people and external systems.
