Vulnerability

A musl crypt sentinel collision can give unauthenticated users shells on Alpine

On musl systems without PAM, an overlong password can hash to the same "*" used for locked accounts; sshd's timing-protection behavior can turn that collision into an unauthenticated shell. The Alpine exposure makes this a serious reminder that sentinel values can undermine authentication logic.

  • WhatA musl crypt sentinel collision can let unauthenticated users obtain a shell on affected musl systems without PAM.
  • Howmusl returns "*" for an overlong password hash, while "*" also marks a locked account; sshd's handling of locked-account attempts joins the conditions.
  • Why it mattersThe bug shows how in-band error sentinels can blur distinct security states; explicit error results can require callers to handle failures.
