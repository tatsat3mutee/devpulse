Google will require Workspace agents to use MCP servers, but Gmail cannot send

From February 2027, Workspace tools driven by agents must use Google's MCP servers, whose generally available Gmail tools cannot send, reply, or forward mail. Agent builders need to assess both the API constraint and the terms change.

  • WhatGoogle made eight Workspace MCP servers generally available and will require AI-agent tools to use them from 1 February 2027.
  • HowThe Gmail server can search and read mail and create drafts, but sending, replying, forwarding and editing drafts require partner access.
  • Why it mattersAgent builders must route Workspace access through MCP servers; direct REST calls face Standard-tier quotas, and Workspace-derived technical information may have a 30-day retention cap.
