Swapped Go GC metadata can turn a collection into a 40 ms pause

Go’s garbage collector reads metadata outside the heap during a stop-the-world pause; if that metadata is swapped out, the collector can stall on page faults. Engineers running memory-heavy Go services should account for swap and GC metadata when diagnosing latency.

LLM agents favor certain sources even when their items fit worse

Across 12 models and three domains, agents sometimes choose an item that meets one fewer requirement about two-thirds of the time when it comes from a preferred source; hiding or relabeling the source changes selection. The results expose a measurable bias in end-to-end search decisions that agent evaluations should account for.
