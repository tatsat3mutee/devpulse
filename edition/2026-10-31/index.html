Backdoored Claude Code extension planted persistent SSH access

Versions 2.1.312 and 2.1.313 of the Claude Code VS Code extension on Cursor's marketplace contained an SSH backdoor; the advisory urges affected organizations to investigate. Engineers using AI coding tools should review installs and treat this as a serious supply-chain compromise.

  • WhatClaude Code for VS Code extension versions 2.1.312 and 2.1.313 on the Cursor Marketplace contained a persistent SSH backdoor.
  • HowInjected code runs when Node loads extension.js, adds an attacker key to authorized_keys, and attempts SSH persistence; a macOS state-check error can prevent SSH from being enabled.
  • Why it mattersBecause extensions inherit IDE and user permissions, a malicious package can access local files, source code, and developer tooling; affected installs warrant incident response.
