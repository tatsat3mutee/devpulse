AnyS1 cuts agent cost by compiling routine decisions into one pass

AnyS1 trains a shared 4B pointer model to handle enumerated workflow decisions and falls back to a larger model when confidence is low; it cuts episode cost by 75–91% across three unseen benchmarks. The results show a concrete way to reduce agent latency and model-call expense without sacrificing task reliability.

  • WhatAnyS1 compiles human-authored procedural skills into routine decision points so agents need not invoke a large model at every step.
  • MethodOffline, it builds Any-DP from grounded decisions and execution trajectories, then trains a calibrated 4B pointer System-1; low confidence falls back to System-2.
  • Why it mattersAcross three unseen benchmarks, it preserved reliability while cutting episode cost by 75–91% and model-call time by 63–92%.
