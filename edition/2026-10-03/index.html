LoopCD improves looped-transformer scores while cutting recurrent compute

Training-free LoopCD raises Ouro-2.6B-Thinking AIME 2024 pass@1 from 61.88% to 73.33% and cuts forward FLOPs by 22.5–48.2% when fewer loops suffice. It turns intermediate recurrent predictions into a decoding signal that can improve quality and reduce inference compute.

  • WhatLoopCD is a training-free contrastive decoding framework for looped Transformers.
  • MethodIt contrasts the final prediction with an earlier recurrent pass, using logits or hidden states to guide token selection.
  • Why it mattersIt can halve recurrent loops while matching or exceeding full-depth unguided baselines, cutting forward FLOPs by 22.5%–48.2%.

PyRUA-Lean raises robot-agent success while using fewer tokens

PyRUA-Lean lets agents compose robot primitives and VLA policies into Python cells with local retries and selective observations; it raises success from 63.1% to 71.7% while using 65% fewer input tokens. The design shows how execution between model calls can improve agent efficiency.

  • WhatPyRUA-Lean is a code-execution framework for robot agents that reduces repeated model calls and redundant observations.
  • MethodIt composes robot primitives and VLA policies into Python cells with checks and retries, returning requested images and state for replanning.
  • Why it mattersAt equal LLM-call budgets, it raises overall success from 63.1% to 71.7%; on jointly solved tasks it uses 65% fewer input tokens.

AgSpec adapts retrieval-based speculative decoding to coding agents

AgSpec retrieves drafts from session, workspace and global corpora, then adapts draft length using verification feedback; it reports up to 4.37× throughput at batch size 1 and 4.76× at batch size 16. The results show how agent-specific context and acceptance behavior can improve inference speed.

  • WhatAgSpec adapts retrieval-based speculative decoding to coding-agent pipelines with agent-specific corpora and draft-length policies.
  • MethodIt retrieves from session, workspace, and global corpora; offline caps and verification feedback set draft lengths and adapt them online.
  • Why it mattersOn two repository-level multi-agent coding benchmarks, it raises throughput over autoregressive decoding up to 4.37× at batch size 1 and 4.76× at batch size 16.

Omni-Embed-Mini adds modalities without changing text embedding weights

The 0.9B-parameter model aligns text, speech, audio, images, video and documents while keeping text weights bit-identical; it reports 49.57 nDCG@10 on MTEB-v2 BEIR-8. The distillation recipe offers a practical route to multimodal retrieval without regressing the text encoder through training.

  • WhatOmni-Embed-Mini maps text, speech, audio, images, video, and visually rich documents into one shared cosine space.
  • MethodIt freezes text-side weights and aligns modality encoders with lightweight projectors and phased LoRA adapters, using frozen-backbone caption embeddings as teacher targets.
  • Why it mattersBit-identical text weights prevent training from regressing text retrieval while extending the model to five additional modalities.
