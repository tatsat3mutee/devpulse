Paper

OPTIC compresses per-layer embeddings while retaining model performance

OPTIC shares token codes across layers and fits decoders to the embeddings’ output path; at about 100× compression, it retains 97.8% of BF16 E4B performance versus 66.3% for the strongest conventional baseline. The results make embedding storage a promising target for model compression.

  • WhatOPTIC compresses Per-Layer Embeddings by storing one quantized code tuple per token and decoding it at each layer.
  • MethodIt fits codes and layer-specific affine decoders to the PLE output path; at about 100× compression, it retained 97.8% of uncompressed performance across seven benchmarks.
  • Why it mattersReducing embedding memory while keeping performance close to the uncompressed model can help engineers scale inference under GPU-memory constraints.
