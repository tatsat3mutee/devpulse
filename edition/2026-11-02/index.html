A utility gate can reduce agent execution compute by screening interactions

The predict-gate-execute-update loop admits candidate interactions based on estimated utility, with ideal compute savings approaching 1/ρ_u and regret bounded by predictor error and utility margin. This frames when lightweight screening can cut the cost of tool use and reasoning.

  • WhatConditional interaction screens candidate interactions before costly System-2 execution.
  • MethodSystem-1 estimates utility; an adaptive threshold admits candidates, and outcomes update the predictor.
  • Why it mattersUnder ideal screening and equal costs, execution compute falls toward 1/ρ_u; prediction errors and distribution shift reduce savings.

Vulnerability

Multipath TCP use-after-free enables remote code execution on Linux

A race involving a retransmitted SYN can free a connection options structure while another thread uses it, enabling kernel memory disclosure or attacker-controlled writes; Go enables multipath TCP by default. Systems with MPTCP listeners should apply their distribution's kernel patch.

  • WhatA remotely exploitable use-after-free bug affects systems with multipath TCP listeners open.
  • HowA retransmitted SYN response races with connection establishment in another thread, allowing access to freed connection options and possible kernel-memory disclosure or buffer overflow.
  • Why it mattersBecause Go uses multipath TCP by default, network-facing services may encounter the vulnerable kernel path; the excerpt advises updating the kernel or disabling MPTCP.
