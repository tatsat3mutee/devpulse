Agents Paper

AutoPILOT lets visual agents run closed-loop game controllers between model calls

Agents can issue a primitive, launch an open-loop macro or write a screen-driven controller; with the same budgets, AutoPILOT reaches 68.6% real-time success versus VISTA's 38.3%, at one-fifth the API cost for equivalent final success. The harness tackles the latency gap in real-time agents.

  • WhatAutoPILOT is a harness that lets visual agents play games that continue running between model calls.
  • MethodA model call can issue a primitive action, start an open-loop macro, or write a closed-loop controller that acts from the screen until handoff.
  • Why it mattersSeparating controller actions from model-call frequency improves real-time play and can reach VISTA’s final success rate at a fifth of its API cost.
