Linux power firmware limits RTX Spark inference to 14 tokens per second

On Linux, the laptop’s GPU reportedly drops to about 780 MHz on wall power, cutting a 120B-model run from roughly 65 tokens per second to under 14; a Windows-only power-management component is identified as the cause. The findings show how firmware and OS support can dominate local inference performance.

  • WhatLinux runs with GPU acceleration on RTX Spark laptops, but native Linux performance is limited by power-management firmware.
  • HowThe encrypted power table is readable only by the Windows driver; Linux GPU clocks fall to about 780 MHz versus roughly 2.2 GHz on Windows.
  • Why it mattersWSL currently keeps full GPU boost while running Linux AI tools, making it a practical option for developers who need performance.
