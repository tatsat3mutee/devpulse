QPACK header expansion can amplify HTTP/3 server memory use thousands-fold

A small HTTP/3 HEADERS frame can expand into many header objects because implementations fail to enforce decoded-header budgets; one unauthenticated connection can exhaust a server. Seven of ten tested implementations were vulnerable, making the attack and listed fixes relevant to server operators.

  • WhatQPACK header expansion can make a small HTTP/3 request consume tens to thousands of times more server memory.
  • HowSome implementations limit compressed size or check decoded size too late; a 1,000,000-byte HEADERS frame can hold about 160,000 unique headers.
  • Why it mattersServers need cumulative decoded-header limits during decoding to prevent remote clients from exhausting memory.
