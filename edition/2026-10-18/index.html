LLMs generate semantics that Lean verifies through RISC-V compilation

The authors describe using LLMs to write formal rules for an interpreter, then proving in Lean that the compiled program preserves them on RISC-V. This connects model-generated code to end-to-end verification across a compiler boundary.

  • WhatThe project uses LLMs to write formal semantics for a programming language and Lean to verify them against its interpreter.
  • HowThe interpreter is compiled to RISC-V; Lean checks that the LLM-written rules predict its behavior for every program.
  • Why it mattersFor verified software, this approach targets the specification bottleneck by checking semantics against an interpreter treated as ground truth.
