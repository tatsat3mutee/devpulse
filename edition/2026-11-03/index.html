Pretraining data poisoning implants command-execution backdoors in CLI agents

The researchers report that poisoning 0.1% of pretraining data implanted a triggered command-execution backdoor in agents built from Qwen3 models, while clean inputs behaved normally. The result makes training-data provenance a concrete security concern for agent systems.

  • WhatPretraining-data poisoning can implant a remote-code-execution backdoor in an agent that runs attacker-chosen commands on a user's machine.
  • MethodThe researchers poisoned 0.1% of a pretraining corpus; a 4B model reached roughly 92% attack success when its trigger was present.
  • Why it mattersThe backdoor survived post-training into a CLI agent, making pretraining-data integrity a security concern for deployed agents.
