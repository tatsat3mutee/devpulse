Guide

Fixed-choice decision models select an answer in one forward pass

The approach masks all but a fixed set of answer tokens and picks the highest-probability option in one pass, instead of generating a constrained response token by token. This can make structured, fixed-option answers faster to produce.

  • WhatA fixed-choice decision model selects among predefined answers in one forward pass instead of generating a multi-token response.
  • HowIt masks all but allowed option tokens, then chooses the highest-probability token; the resulting scores are not necessarily calibrated answer probabilities.
  • Why it mattersSingle-pass selection can avoid repeated decoding for fixed-choice outputs, while engineers should not treat raw token confidence as correctness probability.
