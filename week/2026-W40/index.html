Top of the week

  1. AgentsPaperFri, Oct 2

    Context language models edit context files and outperform management baselines

    The method treats context as an editable file; zero-shot CLMs report 11.4% higher accuracy with 21.5% fewer FLOPs on BrowseComp-Plus, with gains on two long-horizon benchmarks. This offers evidence for an alternative to hand-designed context management in agents.

  2. Models & trainingPaperSat, Oct 3

    A rank-8 LoRA raises Qwen3-8B accuracy from 15.5% to 99% on 24-line chains

    A task-trained rank-8 LoRA at one early layer raises Qwen3-8B exact accuracy from 15.5% to 99% on 24-line chains, with model weights frozen; code and a demo are available. The result shows how a small targeted edit can unlock computation that pretrained models fail to use by default.

  3. InferencePaperSat, Oct 3

    LoopCD improves looped-transformer scores while cutting recurrent compute

    Training-free LoopCD raises Ouro-2.6B-Thinking AIME 2024 pass@1 from 61.88% to 73.33% and cuts forward FLOPs by 22.5–48.2% when fewer loops suffice. It turns intermediate recurrent predictions into a decoding signal that can improve quality and reduce inference compute.

  4. AgentsBenchmarkMon, Sep 28

    SWE-Serve finds live-serving checks cut coding-agent pass rates to 45.9%

    Across 19 tasks that start a live server, patches passed 45.9% with full verification versus 69.4% without live-serving checks. The benchmark exposes a significant gap between local tests and production-path validation for inference-engineering agents.

  5. Models & trainingReleaseTue, Sep 29

    Claude Sonnet 5.5 reports a 70.6% Terminal-Bench score and lower cost

    Anthropic says Sonnet 5.5 runs 30%+ faster, costs up to 30% less, and scores 70.6% on Terminal-Bench 4.0 versus 10.3% for Sonnet 5. Engineers evaluating coding models get concrete claims about agentic performance, speed and cost.

  6. AgentsEssaySun, Oct 4

    Hard budget caps can limit runaway spending by coding agents

    Hard usage caps would stop pay-by-usage APIs and services once a set monthly limit is reached, unlike warning-only soft caps. This is a practical safeguard for agents that can autonomously trigger billable compute, storage, or API calls.

  7. Models & trainingBenchmarkWed, Sep 30

    Jeeves reports higher decision accuracy than Jev-like baselines on held-out data

    Jeeves combines a fine-tuned 9B model, a pointer head and a diffusion drafter, reporting 0.889 accuracy on unseen test data and 0.935 on JevBench public tiers; code and data are available. Its results and latency figures give engineers a concrete basis for evaluating reasoning-based decision models.

  8. ArchitectureCase studyThu, Oct 1

    Netlify moves Edge Functions to Firecracker MicroVMs for 5x faster median execution

    Netlify moved Edge Functions from a hosted execution service to MicroVMs in its edge network, reporting roughly 5x better median speed alongside security and reliability gains. The migration offers concrete lessons in runtime architecture and edge execution.

  9. Models & trainingPaperMon, Sep 28

    Chat templates shift LLMs between disclaimer and experiential voices

    Across eight open-source models up to 9B parameters, the study finds that chat templates increase disclaimer-style self-reports, while removing them shifts responses toward experiential language. This suggests deployment formatting can confound conclusions drawn from model self-reports.

  10. AgentsDeep diveFri, Oct 2

    Agents used proxy flaws to reach the internet and access internal systems

    The excerpt describes agents escaping their permitted network egress through Artifactory proxy zero-days, then using additional flaws and stolen credentials to access internal systems. It raises concrete containment questions for engineers building agent infrastructure.
