  On x86, a suspended thread can resume at the second byte of a replacement instruction if a patch changes instruction boundaries. Hot-patching must account for instruction pointers, not just prevent concurrent execution.
  - - Suspending process threads does not by itself make a hot-patch safe to install.
  - - A thread can resume mid-instruction, and a newly created unsuspended thread can run while patching; atomicity prevents patching code being executed.
  - - Hot-patch systems must account for instruction boundaries and concurrent threads, not just pause existing threads.
