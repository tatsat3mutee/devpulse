AutoMaster uses skill-guided rollouts to improve post-training data

AutoMaster's agent analyzes trajectories and designs skill interventions; across Terminal, Search, and software engineering tasks, it improves mean performance over vanilla SFT by 1.42–8.99 percentage points with the training setup held fixed. This is a practical approach to shaping post-training data without changing the teacher or recipe.

  • WhatAutoMaster is an autonomous post-training system that uses natural-language skills to shape teacher rollouts before fine-tuning a target model.
  • MethodAn LLM agent analyzes trajectories, designs skills, selects data, and uses rollout and target-model evaluation feedback to develop interventions.
  • Why it mattersWith the teacher, task pool, training set size, and SFT recipe fixed, it beats vanilla SFT by 1.42–8.99 points across Terminal, Search, and software engineering tasks.
