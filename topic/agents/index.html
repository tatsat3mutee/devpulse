Opera tracks whether coding-agent feedback actually resolves problems

Opera audits critic feedback against visible evidence, then follows the agent's actions to distinguish compliance from resolution; it raises resolve rates by up to 12.4, 15.0 and 8.9 percentage points on three benchmarks. This offers a concrete way to improve long-horizon agent critique.

  • WhatOpera is a verbal critic that keeps corrections as persistent notes until it determines whether the diagnosed issue is resolved.
  • MethodPeriodic or event-driven reviews diagnose with typed operators, audit feedback against visible evidence, and track later actions.
  • Why it mattersOpera-guided rollouts improved Qwen3.5-9B's held-out SWE-Bench Pro resolve rate by 10.2 points without a critic at inference.

REMORY adds learned memory tokens to compacted agent histories

REMORY appends bounded soft memory tokens to a summary; on SummHay it approaches the full-context joint score using 5.2% of input positions, and it reduces repeated tool outputs and errors on agent benchmarks. This offers a measured approach to context limits in long-running agents.
