General coding agents overtake specialized data agents on newer models

On TAG-Bench and DAB, a general coding agent surpasses Agentar-Scale-SQL in accuracy and token efficiency with GPT-5.6 Sol, reversing the result with o3; the comparison holds the model constant while varying the scaffolding.
