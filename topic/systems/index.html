Virtio-nvgpu gives KVM guests near-native NVIDIA GPU access

Virtio-nvgpu forwards NVIDIA driver ioctls across the VM boundary, letting a guest use the unmodified user-mode drivers; reported rendering is within 2% of bare metal. This is a useful design for GPU-backed workloads that need isolation without paying much virtualization overhead.

  • What- virtio-nvgpu forwards NVIDIA kernel-driver ioctls between a Linux guest and host at the driver ABI level for near-native GPU access.
  • How- The guest runs unmodified NVIDIA user-mode drivers, which submit through mapped host memory without forwarding each render-loop operation.
  • Why it matters- It enables GPU rendering and encoding inside headless VMs, with frame times within 2% of bare metal above about 2 ms per frame.
