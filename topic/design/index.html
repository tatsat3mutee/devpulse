Azure API Connections flaws enable five full cross-tenant compromises

The flaws let attackers compromise other tenants’ API Connections and reach connected services including Key Vault and Azure SQL; the researcher says input validation is the main barrier. It is a serious cloud-isolation failure with lessons for platform architects.

  • WhatFlaws in Azure Logic Apps API Connections let attackers compromise other tenants’ connections and access their connected backend services.
  • HowARM REST API DynamicInvoke or /extensions/proxy/ endpoints can query shared API Management, which exchanges an input token for the victim connection’s backend token.
  • Why it mattersBecause a connection can expose Key Vault, Azure SQL, or other services, engineers should treat connection isolation and backend token scope as security boundaries.
