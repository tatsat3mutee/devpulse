Ollaya runs local decision models in a single forward pass

Ollaya runs decision models locally without token-by-token generation; its example reports about 10 ms end to end for five questions on an RTX 4090. Fast local decisions could be useful in agent workflows where each action needs a lightweight risk check.

  • WhatOllaya is an open-source local runtime for decision models that answer typed questions about text or JSON.
  • HowModels return calibrated choice, score, or yes/no answers in a single forward pass; Ollaya also serves a TypeSafe-compatible API.
  • Why it mattersLocal execution offers millisecond decisions on a user’s own hardware and lets the TypeSafe Python SDK work unchanged against the local server.

Parakeet Redux fits in 178 MB and runs at 113× real time on CPU

Parakeet Redux uses 1.58-bit weights and runs at 113× real time on eight x86 CPU cores; its 178 MB size comes with English WER within 0.3 points of the original and stronger results on some listed benchmarks. The results make it a concrete example of aggressive quantization for fast, compact speech recognition.
