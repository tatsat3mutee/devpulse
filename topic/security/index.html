Supply-chain attackers tampered with update servers in five-to-ten-minute windows

Investigators found repeated brief changes to AOMEI update infrastructure that reverted to authentic files after five to ten minutes, delivering a multi-stage payload. The short windows show why point-in-time scans can miss supply-chain compromises.

  • WhatA campaign targeted AOMEI Technology's update infrastructure between April and July 2026.
  • HowAttackers tampered with origin-server configurations for five to ten minutes, then restored authentic versions; the campaign delivered CROSSROAD and SHINYROAD.
  • Why it mattersBrief tampering windows evaded point-in-time triage and automated file scanning, so update-integrity monitoring must account for changes that quickly revert.
